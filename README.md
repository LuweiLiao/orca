running through Orca on Linux in an isolated, hidden Electron application.

1. `01-real-greeting.png`: the actual reply to `hi`.
2. `02-annotate-greeting.png`: selecting the greeting and entering an English comment.

This evidence validates the Linux workflow; it does not claim cross-device
synchronization or macOS and Windows runtime validation.
